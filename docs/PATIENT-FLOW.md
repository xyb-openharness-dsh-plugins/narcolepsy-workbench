# PATIENT-FLOW · 三条真实时刻

> 页面树由这三条反推，不从医生流程照搬。每条写「在什么时刻最难受 → 打开哪一页 → 得到什么产物」。

## F1 · 一次被误解的周一上午（日常/发作）

- **时刻**：周会进行到一半，患者突然困到无法抵抗，醒来发现同事在看自己。下班后想"这周第几次了？"
- **打开**：L3 嗜睡发作 → 记录发作
- **动作**：记时间点（14:20）、情境（开会）、持续（22 分钟）、前驱感（有·眼皮发沉）
- **产物**：本条记录 + 首页"本周发作 4 次 / 平均 19 分钟"
- **失败恢复**：服务不可用时提示"先记在草稿"，本地暂存不丢

## F2 · 复诊前一晚（整理/出门）

- **时刻**：明天上午门诊，手里有 3 张检查单、1 个药盒、手机里零散记录。不知道该问什么。
- **打开**：L9 复诊准备 → 问题清单（+ L5 量表历史、L7 趋势）
- **动作**：看"这三个月 ESS 从 15 到 12"、勾选 3 个想问的问题（"我现在这个剂量还要不要调"、"白天突然睡着要不要报工伤"）
- **产物**：一页可打印的「本次就诊：我的记录 + 我的问题」
- **边界**：问题清单只记录**我想问**，不生成"医生会怎么答"

## F3 · 单位人事要材料（办事）

- **时刻**：单位要"病情说明"，驾照换证也要材料，患者不知道哪些能给、哪些不该给。
- **打开**：L8 办事与材料 → 材料清单
- **动作**：勾选"诊断证明（有/无）""用药记录（可导出/不导出）"；生成一份只含日期与药物名称的清单
- **产物**：本机生成的文件；**默认不含**夜间事件细节与心理记录（三出口过滤）
- **边界**：不写"符合/不符合某标准"，只列"我有什么"

## 页面树反推

```
看板 L1 ──┬─ 今日概览（最近一次发作/昨夜睡眠/下次复诊）
          ├─ 本周发作（时段柱）
          └─ 待办与问题（跨线汇总）
嗜睡发作 L3 ─ 记录 / 时段聚合 / 情境分布
夜间睡眠 L4 ─ 日志 / 瘫痪与幻觉 / 觉醒统计
量表 L5 ─ 填写 / 历史序列 / 分项（整页视图）
用药 L6 ─ 当前方案 / 换药历史 / 耐受
检查指标 L7 ─ 列表 / 趋势 / 口径
办事材料 L8 ─ 清单 / 导出 / 说明
复诊准备 L9 ─ 问题清单 / 带什么 / 回顾
```
