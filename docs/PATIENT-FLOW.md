# PATIENT-FLOW · 四条真实时刻

> 页面树由这四条反推，不从医生流程照搬。每条写「在什么时刻最难受 → 打开哪一页 → 得到什么产物」。

## F1 · 一次被误解的周一上午（日常/发作）

- **时刻**：周会进行到一半，患者突然困到无法抵抗，醒来发现同事在看自己。下班后想"这周第几次了？"
- **打开**：L3 嗜睡发作 → 记录发作
- **动作**：记时间点（14:20）、情境（开会）、持续（22 分钟）、前驱感（有·眼皮发沉）
- **产物**：本条记录 + 首页"本周发作 4 次" + 本周发作页的「**单次时长中位数**」（演示档案 18 分钟 —— 该值**未核**，见下）
- **失败恢复**：服务不可用时提示"先记在草稿"，本地暂存不丢
- **口径**：本仓只算**单次时长中位数**，**不算平均值**——平均值会被当成"典型病程"，而这些记录是零散事件的抽样，不是全量。
  > 待核：按 `prototypes/v0.2/app.js:285` 同一算式，演示档案 A 的 63 条含时长记录实测中位数为 **25 分钟**（`demo-data.js` 的 `nap_median_min` 最近一点是 23），与上面的 18 不一致；且该卡只出现在「本周发作」二级页，`dashboard/0` 只给「近 7 天 N 次发作」计数（见 `docs/DESIGN-REVIEW.md` P1-4）。本轮只改文档不动原型，**以实测 25 为准**，18 是待核示意值。

## F2 · 复诊前一晚（整理/出门）

- **时刻**：明天上午门诊，手里有 3 张检查单、1 个药盒、手机里零散记录。不知道该问什么。
- **打开**：L9 复诊准备 → 问题清单（+ L5 量表历史、L7 趋势）
- **动作**：看"这三个月 ESS 从 15 到 12"、勾选 3 个想问的问题（"我现在这个剂量还要不要调"、"白天突然睡着要不要报工伤"）
- **产物**：一页可打印的「本次就诊：我的记录 + 我的问题」
- **边界**：问题清单只记录**我想问**，不生成"医生会怎么答"

## F3 · 单位人事要材料（办事）

- **时刻**：单位要"病情说明"，驾照换证也要材料，患者不知道哪些能给、哪些不该给。
- **打开**：L8 办事与材料 → 材料清单
- **动作**：勾选"诊断证明（有/无）""用药记录（可导出/不导出）"；生成一份只含日期与药物名称的清单
- **产物**：本机生成的文件；**默认不含**夜间事件细节与心理记录（三出口过滤）
- **边界**：不写"符合/不符合某标准"，只列"我有什么"

## F4 · 想知道有没有在招的研究（试验线索）

- **时刻**：做完 MSLT，病友群在传"有个新药在招"，患者想知道"我这个情况能不能去问问"，但不想被工作台判定"我能入组"。
- **打开**：看板入口 → `trials/个人建档` → `trials/匹配结果`（+ `trials/试验库`）
- **动作**：
  1. 在 `trials/个人建档` 补 HLA-DRB1\*/DQB1\*、脑脊液食欲素（Orexin-A）、MSLT 平均潜伏期与 SOREMP 次数（**全部选填，留空即"未记录"**；这两项检查不是常规随访项目，补不补由患者/医生决定，见 USER-RESEARCH H6 未验证）；
  2. 在 `trials/匹配结果` 看每个在招试验的**匹配指数**与**缺口维度清单**——匹配指数只对登记库**已登记字段**（状态/分期/国家/入组人数/起止日期）归一化，入排标准与生物标志维度**单列为缺口、不给分**；
  3. 在 `trials/试验库` 看本轮真实采集的 200 条（`ctv` 176 ready / `ictrp` 10 **partial** / `chictr_online` 0 **unsupported** / `chinadrugtrials` 14 ready），每条带来源与终态标注。
- **产物**：一份可带去门诊的「我看到的在招研究 + 我缺哪几项」清单
- **边界（写死在结果页）**：**"以研究中心评估为准"**。登记库没有入排标准与生物标志字段，所以匹配有限；缺口维度**不折算成 0 分**，页面不出现"可入组 / 不符合入组"任何结论。
- **失败恢复**：`partial` / `unsupported` 通道在页面上显式标注"该来源本轮未查通，0 条 ≠ 没有"，不并入"无相关研究"。

## 页面树反推

```
看板 L1 ──┬─ 今日概览（最近一次发作/昨夜睡眠/下次复诊）
          ├─ 本周发作（时段柱）
          └─ 待办与问题（跨线汇总）
嗜睡发作 L3 ─ 记录 / 时段聚合 / 情境分布
夜间睡眠 L4 ─ 日志 / 瘫痪与幻觉 / 觉醒统计
量表 L5 ─ 填写 / 历史序列 / 分项（整页视图）
用药 L6 ─ 当前方案 / 换药历史 / 耐受
检查指标 L7 ─ 指标卡 / 一图秀 / 数据口径
办事材料 L8 ─ 清单 / 导出 / 说明
复诊准备 L9 ─ 问题清单 / 带什么 / 回顾
临床试验 L10 ─ 个人建档 / 匹配结果 / 试验库
```
