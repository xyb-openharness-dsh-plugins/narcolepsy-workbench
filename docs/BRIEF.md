# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：发作性睡病患者；含青少年患者与家长代记、长期误诊后确诊者

场景：白天不可抑制的嗜睡发作影响工作与驾驶安全；ESS 量表与整夜 PSG/MSLT 检查结果分散在多张纸；管制类药物的换药加量与耐受记录；学校/单位/驾照需要的材料整理

核心流程：
1. 选择本机资料目录并导入睡眠检查报告与处方
2. 记录嗜睡发作与夜间睡眠事件
3. 按复诊节奏完成 ESS 量表
4. 记录用药与耐受、生成办事材料
5. 整理复诊问题清单

完成结果：得到来源可追溯的个人病程档案：嗜睡发作时段日志、夜间睡眠事件、ESS 序列、用药与耐受、检查原文与问题清单；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
