# INTERACTION-DESIGN · 交互路径与 CRUD 双通道（HTML 开工前置）

> 判据来自 [28 号交互路径设计](28-INTERACTION-PATH-DESIGN.md)。**没有这份文档不开 HTML 原型（IP1）。**
> 本文件按发作性睡病填写，示例中的入口名与导航 key 必须与原型逐字一致（IP3）。
> 签认：与场景清单、页面树同批进 G1。

## 1. 页面与导航 key（唯一来源，原型与开发版都照抄）

| 导航 key | 一级文案 | 二级 sub（`view/sub`） |
| --- | --- | --- |
| `dashboard` | 看板 | `today` 今日概览 · `week` 本周发作 · `todo` 待办与问题 |
| `diagnosis` | 确诊档案 | `dx` 诊断原文 · `exam` 检查原文 · `timeline` 时间线 |
| `naps` | 嗜睡发作 | `add` 记录发作 · `bucket` 时段聚合 · `context` 情境分布 |
| `night` | 夜间睡眠 | `log` 睡眠日志 · `events` 瘫痪与幻觉 · `awake` 觉醒统计 |
| `ess` | 量表 ESS | `fill` 本次填写 · `history` 历史序列 · `detail` 分项 |
| `meds` | 用药与耐受 | `current` 当前方案 · `switch` 换药历史 · `tolerance` 耐受记录 |
| `metrics` | 检查与指标 | `list` 指标列表 · `trend` 趋势 · `basis` 数据口径 |
| `admin` | 办事与材料 | `checklist` 材料清单 · `export` 导出 · `note` 说明 |
| `visit` | 复诊准备 | `questions` 问题清单 · `bring` 带什么 · `review` 记录回顾 |

**覆盖性**：9 个一级 × 3 个二级 = 27 个 `(view, sub)`，下方路径表必须全覆盖，孤儿页 = 0（IP2）。

## 2. 场景路径表（六要素齐全）

### S01 · 会议里突然睡着，下班后想记下来（F1）

| 要素 | 内容 |
| --- | --- |
| 入口 | 看板 `dashboard/today` → 卡片「今天记一次发作」 |
| AI 路径（默认） | 在会话区说「刚才三点半开会时睡着了，大概二十分钟」→ AI 产出候选卡：时间 15:30 / 情境 开会 / 持续 20 分钟 / 前驱 未记录 → 患者逐项核对 → 确认 |
| 手工路径（收敛） | 同一卡片点「⋯ 更多」→「手工补一条」→ 表单 4 字段（时间滑条·情境三态·时长数字键盘·前驱三态）→ 保存 |
| 产物 | `naps` +1；`dashboard/today` 的「本周发作」计数 +1，`dashboard/week` 时段柱对应小时 +1 |
| 回首页 | 二级页左上「返回」或顶栏品牌 → `dashboard/today` |
| 失败恢复 | AI 没听清 → 候选卡显示「没识别出时间」+「手工填更准」直达表单；拒收候选后 `naps` 不增加（零副作用） |

### S02 · 复诊前一晚，想知道这三个月变化（F2）

| 要素 | 内容 |
| --- | --- |
| 入口 | 看板 `dashboard/todo` → 卡片「3 天后复诊」→「去准备」 |
| AI 路径 | 会话区说「帮我看看这三个月有什么变化」→ AI 读 `ess/history` + `metrics/trend` 产出**只陈述事实**的摘要候选（不含建议）→ 患者核对 → 生成「本次就诊记录」 |
| 手工路径 | `visit/review` 勾选要带的内容（发作汇总 / ESS 序列 / 用药变更 / 指标），生成一页 |
| 产物 | `visit/review` 生成可打印页（含日期、ESS 分数变化、发作次数、当前用药名）；`documents` 记录一条导出记录 |
| 回首页 | 生成后 Toast 内嵌「回到看板」 |
| 失败恢复 | 无 ESS 记录时显式写「还没有量表记录，去填一次」而不是画空图；AI 摘要若出现建议句 → 拒收并要求重写 |

### S03 · ESS 到了该填的时候（F2 配套）

| 要素 | 内容 |
| --- | --- |
| 入口 | 看板 `dashboard/todo` → 卡片「该填 ESS 了」 |
| AI 路径 | —（**红线**：量表分数必须患者自己选，AI 不估算） |
| 手工路径 | `ess/fill` 8 题逐题三态单选（0/1/2/3），顶部进度「3/8」，整次提交后总分由服务端算 |
| 产物 | `ess_sessions` +1；`ess/history` 多一个点；`dashboard/today` 显示「上次 ESS 12 分（10-20）」 |
| 回首页 | 提交后整页返回 `ess/history`（能看到刚填的那次），再「返回」到看板 |
| 失败恢复 | 中途刷新 → 草稿保留（localStorage）；8 题未答完不能提交，提示「还差 2 题」 |

### S04 · 夜里醒来动不了，白天想确认这是不是"正常"（F1 夜间）

| 要素 | 内容 |
| --- | --- |
| 入口 | 看板 `dashboard/today` → 卡片「昨晚睡得怎么样」→「记一条夜间事件」 |
| AI 路径 | 会话区说「凌晨两点醒了但是动不了，大概一分钟」→ 候选卡：02:00 / 睡眠瘫痪 / 1 分钟 → 核对确认 |
| 手工路径 | `night/events` 「⋯ 更多」→「手工补一条」→ 3 字段（时间·类型四选·时长） |
| 产物 | `night_events` +1；`night/awake` 统计 +1 |
| 回首页 | 同 S01 |
| 失败恢复 | 患者不确定类型 → 表单提供「说不好，先记下来」选项（存 `vivid_dream`? 不）→ **存为 `kind` 未定条目并在列表标「待确认」** |

### S05 · 换了药，想知道有没有用、难不难受（F2）

| 要素 | 内容 |
| --- | --- |
| 入口 | 看板 `dashboard/todo` → 卡片「用药有变化吗」 |
| AI 路径 | 拍一张药盒照片或处方 → 候选：药名·剂量原文·开始日期 → 核对 → 确认后**新增一条 meds**（旧方案保留） |
| 手工路径 | `meds/current` 「⋯ 更多」→「记一次换药」→ 4 字段（药名·剂量原文·开始日期·是否管制类） |
| 产物 | `meds` +1 且 `supersedes_id` 指向旧行；`meds/switch` 时间线多一段 |
| 回首页 | 二级页返回 → 看板 |
| 失败恢复 | 药名识别错 → 候选卡每项旁「不对，改一下」；拒收后 `meds` 不变 |

### S06 · 单位要材料，不知道该给哪些（F3）

| 要素 | 内容 |
| --- | --- |
| 入口 | 看板 `dashboard/todo` → 卡片「办事材料」 |
| AI 路径 | 说「单位要病情说明」→ AI 只产出**清单候选**（我有哪些材料 / 哪些不含），不生成证明内容 |
| 手工路径 | `admin/checklist` 逐项勾选「有 / 无 / 可导出」 |
| 产物 | `admin/export` 生成文件；**默认不含**夜间事件细节与 `viewpoints.private=1` 条目（三出口过滤） |
| 回首页 | 导出后 Toast 内嵌「回到看板」 |
| 失败恢复 | 患者不想导出某类 → 导出前有逐类开关，默认全关敏感类 |

### S07 · 想看这段日子的发作到底集中在什么时段（F1 汇总）

| 要素 | 内容 |
| --- | --- |
| 入口 | 看板 `dashboard/week` → 时段柱点某个小时 |
| AI 路径 | —（**红线**：不做「你这个时段要注意」这类建议） |
| 手工路径 | `naps/bucket` 切换周/月；`naps/context` 看情境分布 |
| 产物 | 无可写产物（只读视图），但可「导出这一页」为图 |
| 回首页 | 返回 → 看板 |
| 失败恢复 | 某时段 0 次 → 显示 0 而不是空白（避免"以为没记"） |

### S08 · 看不懂化验单上的数字

| 要素 | 内容 |
| --- | --- |
| 入口 | 看板 `dashboard/today` → 卡片「最近一次检查」 |
| AI 路径 | 粘一段化验单文本/拍照 → 候选指标行（code·值·单位·参考范围）→ 核对 → 入 `metrics` |
| 手工路径 | `metrics/list` 「⋯ 更多」→「手工加一条」→ 5 字段 |
| 产物 | `metrics` +N；`metrics/trend` 多一条线 |
| 回首页 | 二级页返回 → 看板 |
| 失败恢复 | 参考上限缺失 → 徽章「需参考上限」而不是拿别的病上限顶上；`metrics/basis` 写清"这个数字从哪来" |

## 3. CRUD 双通道矩阵

| 实体 | AI 协助（默认） | 手工（收敛） | 说明与红线 |
| --- | --- | --- | --- |
| `naps` 嗜睡发作 | 对话 → 时间/情境/时长/前驱候选 | `naps/add` 或卡片「⋯ 更多」· 4 字段 | 时长可空（NULL ≠ 0）；代记必标 `proxy` |
| `night_events` 夜间事件 | 对话 → 时间/类型/时长候选 | `night/log` 「⋯ 更多」· 3 字段 | 类型四选 + 「说不好」；不推断病因 |
| `ess_sessions` ESS | **— 红线**：AI 不估分量表 | `ess/fill` 8 题整次 | 整次同源；总分服务端派生 |
| `meds` 用药 | 拍药盒/处方 → 药名·剂量原文·起始日候选 | `meds/current` 「⋯ 更多」· 4 字段 | 换药新增行 + `supersedes_id`；剂量只存原文串 |
| `med_tolerance` 耐受 | 对话 → 项目/程度候选 | `meds/tolerance` 「⋯ 更多」· 3 字段 | 不判"严重/轻微"，只记 `item` + `value` |
| `metrics` 指标 | 粘化验单/拍照 → 指标行候选 | `metrics/list` 「⋯ 更多」· 5 字段 | `ref_high` 缺失就显示「需参考上限」，不借别的病上限 |
| `documents` 原文 | 导入 PDF/文本 → 存原文 | 卡片「⋯ 更多」→「看原文」 | 原文只折叠展示，不改写 |
| `questions` 问题清单 | 对话 → 「我想问…」候选 | `visit/questions` 单行输入 | 只记"我想问"，不生成"医生会怎么答" |
| `viewpoints` 我的看法 | — **红线**：不代写看法 | 卡片内联输入 | `private=1` 默认不进一图秀/摘要/导出 |
| `admin` 材料 | 对话 → 清单候选 | `admin/checklist` 勾选 | 不生成"符合某标准"的表述 |
| `profile` 档案 | 对话 → 诊断原文候选 | `diagnosis/dx` 4 字段 | `dx_text` 照抄医生原文，不分型 |

## 4. 删除 = 更正

1. 全站无裸删除；语言统一「改这一条」。
2. 更正新增版本：`meds` 用 `supersedes_id`，其余用 `events` 留痕 + 原记录页可查旧值。
3. `grep -c "不可恢复"` 必须为 0（IP8）。

## 5. IP1–IP10 本项目验法

| # | 红线 | 本项目验法 |
| --- | --- | --- |
| IP1 | 无路径文档不开 HTML | 本文件 + G1 签认记录 |
| IP2 | 双向覆盖，孤儿页 0 | 无头脚本穷举 27 个 `(view,sub)` × S01–S08，输出未覆盖清单 |
| IP3 | 入口逐字一致 | 断言看板卡片文案 == 本文件「入口」列字符串 |
| IP4 | 产物可观察 + 一步回首页 | 每条路径断言产物计数与返回按钮可点 |
| IP5 | AI 默认且候选必核 | 矩阵逐行核对；拒收后行数不变的断言 |
| IP6 | 每页编辑入口 ≤1，表单 ≤6 字段 | 每页计数显式编辑按钮；表单字段数断言 |
| IP7 | 数字输入用键盘组件 | 抽查 `naps/add` 时长、`metrics` 数值、`ess` 分项 |
| IP8 | 无裸删除、无「不可恢复」 | grep = 0 + 更正后旧值可查 |
| IP9 | 双通道同源 | 同一实体手工写一次 + AI 确认一次，事实层只有一条链 |
| IP10 | AI 示例不代替发言 | 每个一级页一处示例；点击后输入框有文案且不发请求 |

## 6. 手工通道收敛数值

| 规则 | 取值 |
| --- | --- |
| 每页显式编辑按钮 | ≤ 1 |
| 手工入口位置 | 统一卡片「⋯ 更多」→「手工补一条 / 改这一条 / 看原文」 |
| 手工表单字段 | ≤ 6（本仓最多 5：`metrics`） |
| 长表单 | 一律藏在「+ 手工添加」之后 |
