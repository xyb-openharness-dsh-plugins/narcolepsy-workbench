# DIFF-MATRIX · 小睡宝（发作性睡病）vs 移植样板 vs 成熟基准

> 对比对象：移植样板 `cervical-workbench`（client 链路底本）· 成熟基准 `breast-cancer-workbench` v0.12.0（26 号口径）。
> 目的不是抄，是逼出"为什么不同"。**换名复用一律打回。**

## 1. 一句话定位差异

| 工作台 | 一句话 |
| --- | --- |
| 乳腺（基准） | 分期与分子决定治疗，长期副作用与随访节奏并重 |
| 宫颈（样板） | 分期与生育保留决定路径，放疗长期影响跟着十年 |
| **小睡宝（本仓）** | **不是"病到哪一步"，而是"我一天里什么时候会睡过去"**——核心维度是**时间轴上的发作**与**警觉度量表**，不是肿瘤负荷或分期 |

## 2. 一级/二级结构（10 一级 / 30 二级）

| # | 一级线 | 患者原话（推导句，0 访谈） | 二级（3–4 段：现状 / 记录 / 资源 / 导出） |
| --- | --- | --- | --- |
| L1 | 看板 | "我今天到底什么状态？" | 今日概览 / 本周发作 / 待办与问题 |
| L2 | 确诊档案 | "我到底是什么病、什么时候确诊的？" | 诊断原文 / 检查原文（PSG·MSLT） / 时间线 |
| L3 | 嗜睡发作 | "我一天困几次、哪个时段最凶？" | 记录发作 / 时段聚合 / 情境分布 |
| L4 | 夜间睡眠 | "夜里到底发生了什么？" | 睡眠日志 / 瘫痪与幻觉 / 觉醒统计 |
| L5 | 量表（ESS） | "我这次比上次好还是差？" | 本次填写 / 历史序列 / 分项详情 |
| L6 | 用药与耐受 | "换了药之后有没有用、难不难受？" | 当前方案 / 换药历史 / 耐受记录 |
| L7 | 检查与指标 | "这些数字怎么看？" | 指标卡 / 一图秀 / 数据口径 |
| L8 | 办事与材料 | "驾照、单位、学校要什么？" | 材料清单 / 导出 / 就医证明说明 |
| L9 | 复诊准备 | "下次去要问什么？" | 问题清单 / 带什么 / 记录回顾 |
| L10 | 临床试验 | "有没有在招的研究？我这个情况该去哪里问？" | 个人建档 / 匹配结果 / 试验库 |

**对比结论**：
- 乳腺 8 一级 / 宫颈 12 一级。本仓 **10 一级**——比乳腺多「嗜睡发作」「夜间睡眠」「临床试验」三条（时间轴、事件日志、试验线索），少「营养」「心理」（非本仓核心，M6 后按需补）。
- 二级 30 ≥ 20（26 号下限）；无一条线二级为 0。
- 「临床试验」这一条**刻意只做线索不做判定**：三个二级分别是"我有什么可登记的生物标志"（个人建档）、"和已登记字段差在哪"（匹配结果）、"登记库本身有什么"（试验库），全链路不产出"我能入组"。

## 3. 刻意不同的地方（≥3 条，实际 7 条）

| # | 维度 | 乳腺/宫颈怎么做 | 本仓怎么做 | 为什么必须不同 |
| --- | --- | --- | --- | --- |
| D1 | 核心指标形态 | 肿瘤标志物/生化值，按日期成序列 | **时长型数值**（`duration_min` 每次发作持续分钟）+ **时段计数**（按 0–23 点分桶） | 发作是**离散事件**，按天一行会压扁信息；家族无"时长型"先例 |
| D2 | 趋势图默认 | 数值线为主，分类节点为辅 | **时段柱 + 单次时长线 + ESS 总分线**三视图并列 | 患者三个不同问题（何时/多久/多重），不能塞进一张图 |
| D3 | 量表 | 无（乳腺不用量表） | **ESS 8 题整次入档**，总分派生、分项进整页视图 | 量表必须整次同源；拆散=数据不可比 |
| D4 | 安全维度 | 化疗副作用/淋巴水肿 | **驾驶与操作机械**（只记事实，不给结论） | 本病最现实的伤害是交通事故；红线：不写"可/不可驾驶" |
| D5 | 管制药 | 常规处方 | **管制类药品**：处方来源、换药、查验材料清单 | 国内属精神药品管制；记录方式与证明材料是刚需 |
| D6 | 夜间事件 | 无 | **睡眠瘫痪 / 入睡幻觉 / 夜间觉醒** 三类事件枚举 | 与白天嗜睡不同源，混在一起会失真 |
| D7 | 临床试验线索线 | 乳腺「临床」下有「试验线索」，宫颈「临床研究」三个二级；两者都能顺着登记库看到线索，但**都不显式说"匹配有限"** | **个人生物标志建档 → 结构化匹配 → 明确标出"登记库没有入排字段所以匹配有限"**。匹配指数只对**已登记字段**归一化（状态/分期/国家/入组人数/起止日期），入排标准与生物标志维度**单独列成缺口**，不给分、不参与归一化 | 试验登记库（CTV / ICTRP / ChiCTR / CDE）本来就没有结构化的入排与 HLA/食欲素字段。把缺口当 0 分等于替登记库编造入排，患者会拿着一个"87 分可入组"去挂号——这是本仓最不能犯的错 |

**D7 怎么验**（场景 → 功能 → 验收）：
- 场景：患者刚做完 MSLT，看到病友群在传"有个新药在招"，想知道自己"能不能去问"。
- 功能：`trials/个人建档` 逐项登记 HLA-DRB1\*/DQB1\*、脑脊液食欲素（Orexin-A）、MSLT 平均潜伏期与 SOREMP 次数（可留空，空即"未记录"）；`trials/匹配结果` 对每个试验列出**已登记字段的符合情况**与**缺口维度清单**；`trials/试验库` 是本轮 200 条真实记录的只读视图（含 176 ready / 10 partial / 14 ready 的来源标注）。
- 验收：①匹配结果页**必须**出现"登记库无入排标准与生物标志字段，匹配有限，以研究中心评估为准"这句原文；②缺口维度在 UI 上**不显示分数、不参与归一化**（单测断言：缺 3 个维度时匹配指数的分母等于已登记维度数，不是总维度数）；③任何页面不出现"可入组/不符合入组"结论。

## 4. 一级线重名率实测（≤70% 才过）

重算口径：本仓按 **10 个一级页**算（旧口径 9 个，加入「临床试验」后必须重算，分母不许沿用旧值）。名称逐字比对，不做近义合并——旧口径里"检查与指标≈检查与指标"这种近似折叠本轮不再使用，避免把分母改小。

| 口径 | 分子 / 分母 | 算式 | 结果 |
| --- | --- | --- | --- |
| 一级线名称与乳腺完全同名 | 看板 | 1 / 10 | **10%** |
| 一级线名称与宫颈完全同名 | 看板、检查与指标、复诊准备 | 3 / 10 | **30%** |
| 一级线名称并集重名率 | 对乳腺（8 名）∪ 宫颈（12 名）去重后 **15 个名称**求交集，命中 看板 / 检查与指标 / 复诊准备 | 3 / 10 | **30%** |

对乳腺 8 名：`{看板, 病情整理, 病情一图秀, 临床, 营养支持, 心理支持, 全程与康复, 收藏与回顾}`
对宫颈 12 名：`{看板, 病情整理, 我的分期, 治疗历程, 性与生育, 放疗与长期影响, 检查与指标, 病情一图秀, 营养支持, 心理支持, 复诊准备, 临床研究}`
并集 15 名，与本仓 10 名交集 = `{看板, 检查与指标, 复诊准备}` → **3 / 10 = 30%**。

**结论：30% ≤ 70%，通过。** 新增的「临床试验」与宫颈「临床研究」、乳腺「临床」**不是同名**（本仓用"试验"而两家用"研究/临床"），但没有靠改名过关——D7 的差异落在数据口径与"缺口不算分"这条硬约束上。

> 仍未验的一条：70% 判据本身要求"一级名称一致率 > 70% **且**二级顺序一致"才判抄（`docs/26:111`）。本轮只算了名称一致率，**二级顺序一致性未逐条比对**（未验）。

## 5. 明确不做（写下来才算决定过）

- 不做 1 型/2 型分型判断（分型影响用药，属医生决策）。
- 不做 MSLT/PSG 判读（只录原文数值与单位）。
- 不做药物剂量/换药建议；不做"能否开车"结论。
- 不做儿童起病专属流程（学校沟通、生长发育）——M6 后另议。
- 不接云端解析（本轮无资料目录，MinerU 不接）。
