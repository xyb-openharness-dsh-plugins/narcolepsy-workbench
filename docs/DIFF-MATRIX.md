# DIFF-MATRIX · 小睡宝（发作性睡病）vs 移植样板 vs 成熟基准

> 对比对象：移植样板 `cervical-workbench`（client 链路底本）· 成熟基准 `breast-cancer-workbench` v0.12.0（26 号口径）。
> 目的不是抄，是逼出"为什么不同"。**换名复用一律打回。**

## 1. 一句话定位差异

| 工作台 | 一句话 |
| --- | --- |
| 乳腺（基准） | 分期与分子决定治疗，长期副作用与随访节奏并重 |
| 宫颈（样板） | 分期与生育保留决定路径，放疗长期影响跟着十年 |
| **小睡宝（本仓）** | **不是"病到哪一步"，而是"我一天里什么时候会睡过去"**——核心维度是**时间轴上的发作**与**警觉度量表**，不是肿瘤负荷或分期 |

## 2. 一级/二级结构（9 一级 / 26 二级）

| # | 一级线 | 患者原话（推导句，0 访谈） | 二级（3–4 段：现状 / 记录 / 资源 / 导出） |
| --- | --- | --- | --- |
| L1 | 看板 | "我今天到底什么状态？" | 今日概览 / 本周发作 / 待办与问题 |
| L2 | 确诊档案 | "我到底是什么病、什么时候确诊的？" | 诊断原文 / 检查原文（PSG·MSLT） / 时间线 |
| L3 | 嗜睡发作 | "我一天困几次、哪个时段最凶？" | 记录发作 / 时段聚合 / 情境分布 |
| L4 | 夜间睡眠 | "夜里到底发生了什么？" | 睡眠日志 / 瘫痪与幻觉 / 觉醒统计 |
| L5 | 量表（ESS） | "我这次比上次好还是差？" | 本次填写 / 历史序列 / 分项详情 |
| L6 | 用药与耐受 | "换了药之后有没有用、难不难受？" | 当前方案 / 换药历史 / 耐受记录 |
| L7 | 检查与指标 | "这些数字怎么看？" | 指标列表 / 趋势 / 数据口径 |
| L8 | 办事与材料 | "驾照、单位、学校要什么？" | 材料清单 / 导出 / 就医证明说明 |
| L9 | 复诊准备 | "下次去要问什么？" | 问题清单 / 带什么 / 记录回顾 |

**对比结论**：
- 乳腺 8 一级 / 宫颈 12 一级。本仓 **9 一级**——比乳腺多「嗜睡发作」「夜间睡眠」两条（时间轴与事件日志），少「营养」「心理」（非本仓核心，M6 后按需补）。
- 二级 26 ≥ 20（26 号下限）；无一条线二级为 0。

## 3. 刻意不同的地方（≥3 条，实际 6 条）

| # | 维度 | 乳腺/宫颈怎么做 | 本仓怎么做 | 为什么必须不同 |
| --- | --- | --- | --- | --- |
| D1 | 核心指标形态 | 肿瘤标志物/生化值，按日期成序列 | **时长型数值**（`duration_min` 每次发作持续分钟）+ **时段计数**（按 0–23 点分桶） | 发作是**离散事件**，按天一行会压扁信息；家族无"时长型"先例 |
| D2 | 趋势图默认 | 数值线为主，分类节点为辅 | **时段柱 + 单次时长线 + ESS 总分线**三视图并列 | 患者三个不同问题（何时/多久/多重），不能塞进一张图 |
| D3 | 量表 | 无（乳腺不用量表） | **ESS 8 题整次入档**，总分派生、分项进整页视图 | 量表必须整次同源；拆散=数据不可比 |
| D4 | 安全维度 | 化疗副作用/淋巴水肿 | **驾驶与操作机械**（只记事实，不给结论） | 本病最现实的伤害是交通事故；红线：不写"可/不可驾驶" |
| D5 | 管制药 | 常规处方 | **管制类药品**：处方来源、换药、查验材料清单 | 国内属精神药品管制；记录方式与证明材料是刚需 |
| D6 | 夜间事件 | 无 | **睡眠瘫痪 / 入睡幻觉 / 夜间觉醒** 三类事件枚举 | 与白天嗜睡不同源，混在一起会失真 |

## 4. 一级线重名率实测（≤70% 才过）

| 口径 | 计算 | 结果 |
| --- | --- | --- |
| 一级线名称与乳腺完全同名 | 看板、病情整理、复诊准备 | 3 / 9 = 33% |
| 一级线名称与宫颈完全同名 | 看板、复诊准备 | 2 / 9 = 22% |
| 一级线名称并集重名率（对乳腺 ∪ 宫颈 去重后 14 个名称） | 看板/复诊准备/检查与指标≈"检查与指标" | **3 / 9 = 33%** |

**结论：33% ≤ 70%，通过。** 且 6 条刻意差异中 D1/D2/D3/D4/D6 全部落在功能与数据形态层，不是改名。

## 5. 明确不做（写下来才算决定过）

- 不做 1 型/2 型分型判断（分型影响用药，属医生决策）。
- 不做 MSLT/PSG 判读（只录原文数值与单位）。
- 不做药物剂量/换药建议；不做"能否开车"结论。
- 不做儿童起病专属流程（学校沟通、生长发育）——M6 后另议。
- 不接云端解析（本轮无资料目录，MinerU 不接）。
