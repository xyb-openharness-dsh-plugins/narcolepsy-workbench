## 补齐条件（下一轮）

1. 取得原件（PDF 或官方网页），`sha256` 入 `guidebooks/manifest.json`；
2. 抽 3 条带页码的条目，登记 `refs.json`（页码 + 表号 + ≤200 字摘录）；
3. `manifest.json` / `refs.json` / `cadence.json` 三处 `id/version/published/sha256` 逐字一致 + 单测钉住；
4. 原件 `guidebooks/` **不进** `package.json` 的 `files`（`npm pack` 要能证明没进去），派生件必须随包分发。
